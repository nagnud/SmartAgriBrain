# SmartAgriBrain

## 当前目录说明

- `docs/`：项目架构、接口契约和协同评审文档。阅读顺序见 [docs/README.md](docs/README.md)。
- `esp32/`：通用 ESP32 采集节点的 PlatformIO/Arduino 工程。该节点负责农业传感器采集、MQTT 数据上报，以及后续二维舵机云台控制；由 ESP32 负责人维护。
- `frontend_dashboard/`：Web 管理端及其现有本地后端原型。
- `esp32c5_voice_display/`：规划中的 ESP32-C5 语音与屏幕终端目录。该目录当前尚未出现在工作区；C5 现有工程归位时必须使用此目录名，避免与采集 ESP32 混放。

## 设备职责

- 通用 ESP32：采集土壤湿度、光照、温度、CO2 等农业数据；通过 MQTT 上报；后续控制二维舵机云台。
- ESP32-C5：屏幕显示、语音采集/播放、通过后端完成云端大模型语音会话；不承担农业传感器采集和二维云台控制。
- `smartagribrain-api`：唯一云端入口，负责 MQTT 接入、数据存储、语音/大模型代理和向前端、C5 提供 API。

## 本次状态

本仓库当前只更新文档和目录说明，未移动、删除或修改任何业务代码。`esp32/.pio/` 是 PlatformIO 本机构建产物，不属于源代码目录，也不应纳入版本控制。
